# Decisions

Architectural Decision Records (ADRs). Append-only WHY log.

Filename: `DEC-NNN-<slug>.md`. Numbers are sequential; never
reused. Template: `../templates/decision.md`.

A decision goes here when:
- It changes a contract (`../docs/conventions/contracts.md`).
- It chose between non-obvious alternatives.
- An operator + agent will want to remember "why did we do it this
  way?" in six months.

Not every code choice needs one. The bar: "would a future agent
re-litigate this question without the record?"

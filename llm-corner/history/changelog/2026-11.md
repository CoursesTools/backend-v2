## 2026-11

- 2026-11-05 [payments][subscriptions][tv][claude] Stripe access now moves
  only on paid invoices:
  - Lifecycle webhooks are metadata-only.
  - A paid invoice grants exactly its own line period.
  - Stripe renewals get a 1-day settlement window before grace.
  - V16 restores user 3074's subscription 4999 to its last paid expiry.

  (`fix/stripe-paid-invoice-only-extension`; DEC-005, C2, C6.)
- 2026-11-05 [payments][alerts][claude] A Stripe subscription deletion now
  revokes the customer's alert subscriptions. Before, cancelled customers kept
  receiving alerts, because deletion bypassed the expiry job that removes
  them (`fix/stripe-paid-invoice-only-extension`).
- 2026-11-05 [alerts][claude] The alert-bot subscription confirmation is now
  sent only after a subscribe. It is never sent on unsubscribe, expiry or
  Telegram unlink, and never for a missing Telegram id. This ends the hourly
  `400 Bad Request` and the false "subscribed" messages to expired users
  (`fix/stripe-paid-invoice-only-extension`).
  Companion delivery fixes in the alert repos (shipped, see below):
  - alert-bot-v2 `fix/reliable-telegram-delivery`:
    - 5s connect timeout and classified retries;
    - requeue plus outage abort;
    - thread-safe buffer and 4096-char chunking;
    - DB retry;
    - proxy and base-URL switches.
  - alert-router `fix/per-bot-webclient`: per-bot WebClients.
- 2026-11-05 [alerts][claude] The alert delivery fixes above shipped:
  alert-bot-v2 PR #1 and alert-router PR #2 are merged and deployed. The
  router deploy needed a re-run after a GHCR pull race; the new image was
  verified with 34 sent and 0 failed.
- 2026-11-05 [subscriptions][alerts][claude] Grace now **pauses** alerts
  instead of deleting them:
  - the alert bot delivers only to GRANTED/PENDING CoursesTools subscribers;
  - the backend deletes a user's alert list only after a termination, and
    only if no other subscription is current;
  - grace length moved from a constant to `system_settings` (admin-web
    Settings, 1–30, fallback 7);
  - the customer API returns `gracePeriodEndsAt`.

  (`fix/stripe-paid-invoice-only-extension`; DEC-006, C13, C18;
  alert-bot-v2 `feat/alert-security-and-stats`.)
